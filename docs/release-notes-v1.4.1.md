# Display Fault Simulator v1.4.1

## English

The first public GitHub release of Display Fault Simulator.

### Included

- Full-screen, touch-through Android overlay
- Full physical display bounds, including status bar, navigation bar, and display cutout areas
- Multiple configurable lines with opacity, glow, flicker, and timed position shifting
- Direct drag editor and reusable custom scenes
- Countdown start and automatic stop
- Quick Settings tile and persistent notification controls
- Cracked glass, dead pixels, liquid damage, ghosting, and scanline effects
- Nine built-in preset scenes
- English and Traditional Chinese interfaces that follow Android language settings

## 繁體中文

這是 Display Fault Simulator（螢幕故障模擬器）的第一個 GitHub 公開版本。

### 內容

- Android 全螢幕透明覆蓋效果，觸控完全穿透
- 完整涵蓋螢幕實體範圍，包含狀態列、導覽列與挖孔區域
- 多條線，可調整透明度、光暈、閃爍與定時位置微移
- 直接拖曳編輯器與可重複使用的自訂場景
- 倒數啟動與自動停止
- 快速設定磁貼與常駐通知控制
- 螢幕破裂、壞點、漏液、殘影及掃描線效果
- 九組內建場景預設
- 英文與繁體中文介面，跟隨 Android 語言設定
