# Display Fault Simulator 1.7.0

## 繁體中文

### 破裂效果進階

- 每個場景最多 6 個可直接拖曳的撞擊點
- 可調整旋轉角度、分支數量、延伸長度與裂紋顯示範圍
- 新增邊緣缺角、玻璃碎片、局部反光與手機傾斜視差
- 套用預設時可重新隨機產生裂紋

### 更多面板故障

- OLED 黑斑擴散、綠紫漏液邊緣、亮度不均與暗角
- 彩虹色偏、壓傷光斑、橫向撕裂與局部黑屏
- 白／綠閃屏、AMOLED PWM 條紋及排線跳動

### 動態場景

- 故障逐步出現、漏液／黑斑擴散及不穩定線條
- 事件時間軸、隨機故障與可調間隔的效果循環
- 搖晃、翻轉、開始充電或解鎖時可觸發目前或指定場景

## English

### Advanced cracked glass

- Up to 6 directly draggable impact points per scene
- Adjustable rotation, branch count, reach, and crack-region masks
- Chipped edges, glass shards, local reflections, and tilt parallax
- Optional crack randomization whenever a preset is applied

### More panel faults

- Expanding OLED black spots, green/purple edge bleed, uneven brightness, and vignette
- Rainbow color shift, pressure spots, horizontal tearing, and partial blackout
- White/green flashes, AMOLED PWM bands, and loose-cable jumping

### Dynamic scenes

- Animated reveal, expanding liquid/black spots, and unstable lines
- Event timeline, randomized faults, and configurable effect cycling
- Shake, flip, charging, or unlock events can trigger the current or a selected scene
