# Display Fault Simulator 1.8.1

## 繁體中文

- 修正裝置或 App 畫面旋轉時，故障效果跟著介面轉向的問題
- 線條、裂紋、漏液、壞點等效果現在固定於螢幕硬體座標
- 支援 0°、90°、180°、270° 的反向旋轉補償
- 保留全螢幕覆蓋與觸控穿透行為

## English

- Fixed fault effects rotating with the app UI when the device orientation changes
- Lines, cracks, liquid damage, dead pixels, and other effects now remain anchored to the physical display coordinates
- Added inverse rotation compensation for 0°, 90°, 180°, and 270° orientations
- Preserved full-screen coverage and touch-through behavior
